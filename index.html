Guide Question: What happens to the number of operations when the array size increases? In the worst-case scenario (when the target number is at the very end or not in the array), the number of operations increases linearly in direct proportion to the array size (n). Doubling the array size doubles the maximum number of operations required.

Guide Question: Why does the program perform fewer operations when the number is found immediately? Because the loop starts checking from the first element (index 0). Once it finds a match on the very first comparison, the break statement immediately stops the loop. It skips checking the rest of the array, always taking just 1 operation (Ω(1)) regardless of how large the array grows.

Guide Question: What happens to the number of operations when you increase the array size? The number of operations increases strictly linearly (Θ(n)) to match the exact size of the array. Unlike searching, calculating a sum cannot stop early—it must visit every single element from start to finish in both best and worst cases.
